### Zettelkasten

- External structure to think, which compensates limitations of brain
  - Brain reinvents and rewrite memory every time when retrieving information
  - Brain is a machine for jumping to conclusions
  - If we have an old but forgotten idea again -> brains get excited like first time
- Job split between brain and Zettelkasten -> co-evolving
  - Brain: Focus on gist, deeper understanding, big picture --> brain is good associations, spotting patterns and similarities
  - Zettelkasten: Details and References -> Long-term memory that keeps information objectively unaltered
- What to do next? Do not brainstorm - instead Slip-box-storming: look into Zettelkasten (Contexts/Threads, Clusters, Questions, ...)
