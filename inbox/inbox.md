## Resources

- Inbox: fleeting notes
- Reference System: literature notes *very short and selective note about content in own words + bibliographic detail*
- Slip-Box: Permanent notes
  - Slip-Box only contains what is relevant/interesting 
    - not collect - develop ideas, arguments and discussions
  - Permanent note 
    - exactly one note for each idea
    - Use full sentences
    - disclose your sources
    - Make references
    - be precise, clear and brief as possible

## Workflow

- Process notes in inbox daily
  - How they relate to what is relevant? Does the new information contradict, correct, support or add to what is already in the Slip-Box or in mind?
  - Create permanent notes
    - Add permanent notes to slip-box
      - File one behind one or more related notes (if it does not relate to any note -> file it behind the last one)
      - Add linkt to related notes
      - link it to an index or entry point, which is also linked to index
  - Delete fleeting notes
  - Move literature notes to reference system

- Develop topics, questions, research projects bottom up from within the system
  - what is there
  - what is missing
  - what question arise
  - Read more to challenge, strenghten, change and develop argumente to the new information you are learning
  - do not brainstorm for topics -> Look into the slip-box

## The Workflow Loop

1. GTD: Identifies a book to read (Project/Action).
2. Deep Work: A 90-minute session dedicated to reading and taking "fleeting notes."
3. Smart Notes: Converting those fleeting notes into "permanent notes" during or after the Deep Work session.
4. GTD: Filing the finished book or starting a new research task based on a gap discovered in the Zettelkasten.
