# Kues, Nikolaus von (1401-1464, Kues)

## Thesis

* Das eigentliche Wissen besteht im Bewusstsein des Nichtwissens
* Wahre Philosophie steht im Dienst der Theologie
* Denker der Renaissance
* Gibt es eine Wahrheit, in der die Widersprüche über Gott und die Welt aufgelöst werden können?
* Rationales Erkenntnis bewegt sich in einem Netz sich ausschließender Gegensätze und logischer Widersprüche (Etwas existiert oder nicht, ist rund und dann aber nicht eckig etc.)
  * Für die Erkenntnis von Gott müssen Gegensätze überschritten werden => Gott ist eine Einheit der Koinzidenz => Vereinigung oder Zusammenfall von Gegensätze auf einer höheren Ebene => Wissen um diese Einheit ist verbunden mit dem Verzicht auf das Wissen im üblichen Sinne
* Unwissenheit über Gott => Wenn der Grund dieser Unwissenheit erkannt und die Grenzen des Erkenntnisvermögens bewusst wird => bewusste und belehrte Unwissenheit
* Gott ist als Zahl das Maximum = Unendlich, als Form der Kreis, Kugel. Unendliche Vierecke erreichen nie den Kreis. Menschen stecken in diesen Vierecken drin und können sich dem Kreis (Gott) immer nur annähern.
* Pardoxes, Gegenteiliges, Widersprüche, Sprache, Logik,.. Laufen leer bei der Erkenntnis von Gott => Gott ist alles was sein kann
* Erkenntnis von Gott über Vernunft nicht möglich => Ein Weg Mystik
* Welt und Kosmos (ähnlich wie Gott) nie im Ganzen erfassbar => Man kann sich immer nur annähern
 * Kosmos ist eine eingeschränkte Unendlichkeit => Gott ist eine uneingeschränkte Unendlichkeit
* Erde ist ein Planet und irgendwo im unendlichen Kosmos (nicht im Mittelpunkt)
* Erde durchläuft eine kreisförmige Bahn
* Bewohner anderer Planeten möglich
