# 4.2 Earned Value Management

> Definition von Earned Value Management: Erhebung und Berechnung der Leistungskennzahlen eines Projektes zu einem gegebenen Zeitpunkt auf Basis der drei Kenngrößen

* Earned Value
  * (= Fertigstellungswert) bewertet die Ist-Leistung des Projektes mit dem Ist-Fertigstellungsgrads auf Basis des Planbudgets
  * Der Earned Value beantwortet die Frage: Was hat das, was wir bisher geschafft haben, für einen Wert auf Basis des geplanten Budgets
* Planned Value
  * Bestimmt den Sollzustand zu einem bestimmten Stichtag
  * Auf der Kostensummenlinie (kumulierte Kosten über die Zeit, Cost Baseline) wird einfach das heutige Datum abgetragen
  * Der Planned Value beantwortet die Frage: Wo wollten wir heute eigentlich stehen?
* Actual Cost
  * = Ist-Kosten
  * Dies sind die bis zum Stichtag tatsächlich angefallenen Kosten für das Projekt
  * für die Projektkostenrechnung nicht entscheidend, ob diese Kosten auf einem tatsächlichen Geldfluss, einer internen Verrechnung oder einer rein kalkulatorischen Zuordnung beruhen
  * Die Actual Cost beantwortet die Frage: Was haben wir bisher ausgegeben?

Kennzahl (Kürzel) | Beschreibung
--- | ---
Planned Value (PV) | Planfertigstellung / Plankosten des Projekt zum Stichtag
Earned Value (EV) | Fertigstellungswert zum Strichtag => Fertigstellungsgrad x Gesamtbudget (BAC)
Actual Cost (AC) | Aufgelaufene Ist-Kosten zum Stichtag
Budget at Completion (BAC) | Geplantes Gesamtbudget
Cost Variance (CV) | Kostenabweichung (absolut) zum Stichtag => EV - AC
Cost Performance Index (CPI) | Kostenentwicklungsindex (relativ) zum Stichtag => EV / AC
Schedule Variance (SV) | Terminabweichung (absolut) zum Stichtag => EV - PV
Schedule Performance Index (SPI) | Terminentwicklungsindex (relativ) zum Stichtag => EV / PV
Estimate at Completion (EAC) | Prognose Kosten zum Projektende => BAC / CPI
Estimate to Complete (ETC) | Prognose Restkosten ab heute => EAC - AC
Variance at Completion (VAC) | Prognose Budgetüber- oder -unterschreitung zum Projektende => BAC - EAC
