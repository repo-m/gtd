# #Endianness / Byte Order

- The Date Format Analogy:
  - #BigEndian (Year-Month-Day):** You start with the largest unit. *Example: 2026-01-02.* -> Matches the order you see when you write the Hex number on paper
  - #LittleEndian (Day-Month-Year):** You start with the smallest unit. *Example: 02-01-2026.*
