# Task

Replace every remaining raw pixel literal and static inline `style` object across `TableView.tsx`, `ReqTreeLine.tsx`, `ContextMenu.tsx`, and `MenuBar.tsx` with CSS classes and design tokens.

## Specs to load

- `specs/51-styling-architecture.md` — §"No raw values — tokens only", §"CSS classes for interactive states"
- `specs/50-theming.md` — full token reference

## Acceptance criteria

1. **`TableView.tsx`** — `<th>` cells and `<tfoot> <td>` have no raw `padding` or `fontSize` values; these properties live in CSS classes using `var(--space-*)` and `var(--font-size-*)` tokens.
2. **`ReqTreeLine.tsx`** — the num-label `<span>` has no inline `marginRight: 4`; the value moves to a CSS rule using `var(--space-2)`.
3. **`ContextMenu.tsx`** — menu item `padding` and `fontSize` are expressed in CSS rather than inline style; no raw `px` or numeric literals remain in the component (note: `onMouseEnter`/`onMouseLeave` are removed by BUG-002 and must not be re-introduced).
4. **`MenuBar.tsx`** — the "No matches" `<span>`, the View-tab `<label>`, and the View-tab `<select>` have no inline `style` props; their presentation is expressed in named CSS classes in `styles.css`.
5. `npx tsc --noEmit` exits 0.

## Done when

None of the four listed component files contains a raw pixel literal or a static inline `style` prop.

## Gate command

```
npx tsc --noEmit
```

## Out of scope

- Inline styles in `StatusBar.tsx` — BUG-004 (already active or done).
- Focus/selection state inline styles in `TableView.tsx` — BUG-001.
- The resize-handle `rgba()` in `TableView.tsx` — BUG-003.
- `ContextMenu.tsx` mouse-enter/leave handlers — BUG-002.
- Any component not listed above.
- Behavioural or layout changes of any kind.

## Ordering note

BUG-002 (ContextMenu hover) should be completed before this task. If it is not, the agent must not remove the `onMouseEnter`/`onMouseLeave` handlers here — only fix the raw values.
