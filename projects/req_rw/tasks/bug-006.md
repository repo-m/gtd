# Task

Correct the `.menu-bar` base `font-size` declaration in `styles.css` from `var(--font-size-md)` to `var(--font-size-sm)` to match the MenuBar sizing spec.

## Specs to load

- `specs/60-menubar.md` — §"Sizing": font size for all MenuBar controls is `var(--font-size-sm)`
- `specs/50-theming.md` — token values (`--font-size-sm` = 12 px, `--font-size-md` = 13 px)

## Acceptance criteria

1. `src/frontend/styles.css` has `.menu-bar { font-size: var(--font-size-sm); }` — not `--font-size-md`.
2. No other rules in `styles.css` are changed.
3. `npx tsc --noEmit` exits 0.

## Done when

The single wrong token in the `.menu-bar` rule is corrected.

## Gate command

```
npx tsc --noEmit
```

## Out of scope

- Any other CSS rule or component file.
- MenuBar layout, grouping, or behaviour.
