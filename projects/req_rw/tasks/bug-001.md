# Task

Replace the inline-style `background` and `outline` conditionals on focused table rows and cells in `TableView.tsx` with CSS class names, so focus state is expressed through the class contract defined in the styling architecture spec.

## Specs to load

- `specs/51-styling-architecture.md` — the `.is-focused` class contract
- `specs/50-theming.md` — token semantics for `--color-bg-selected`, `--color-bg-hover`, `--color-border-focus`
- `specs/30-table-view.md` — table focus model (cell focus, row highlight, child-row highlight)

## Acceptance criteria

1. `TableView.tsx` has no inline `background` or `outline` props on `<tr>` or `<td>` elements — all selection and focus state is applied via `className`.
2. `styles.css` contains CSS rules for the focused-row, child-of-focused-row, and focused-cell states using only `var(--*)` tokens; no raw hex, `rgb()`, or pixel literals appear in those rules.
3. Visual behaviour is unchanged: a focused row shows `var(--color-bg-selected)`, its descendant rows show `var(--color-bg-hover)`, and the focused cell shows a `var(--color-border-focus)` outline at `-2px` offset.
4. `npx tsc --noEmit` exits 0.

## Done when

`TableView.tsx` applies focus and selection state exclusively through CSS class names, with no `style` prop carrying those values.

## Gate command

```
npx tsc --noEmit
```

## Out of scope

- Other inline styles in `TableView.tsx` — `th` padding, tfoot sizing, resize-handle background — those are BUG-003 and BUG-005.
- Focus styling in any other component.
- Changing the focus model or which cells/rows receive focus.
