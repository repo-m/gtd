# Task

Replace the `onMouseEnter` / `onMouseLeave` hover handlers in `ContextMenu.tsx` with a CSS `:hover` rule, eliminating the only first-party violation of the hover-via-CSS-only rule.

## Specs to load

- `specs/51-styling-architecture.md` — §"Hover states via CSS only"
- `specs/50-theming.md` — `--color-bg-hover` token used for hover background

## Acceptance criteria

1. `ContextMenu.tsx` has no `onMouseEnter` or `onMouseLeave` event handlers anywhere in the file.
2. A CSS rule in `styles.css` applies `background: var(--color-bg-hover)` on hover for non-disabled context menu items; disabled items show no hover change.
3. Hover behaviour is visually unchanged.
4. `npx tsc --noEmit` exits 0.

## Done when

`ContextMenu.tsx` contains no mouse-enter or mouse-leave handlers; hover feedback is entirely CSS-driven.

## Gate command

```
npx tsc --noEmit
```

## Out of scope

- Raw pixel values in `ContextMenu.tsx` — padding, font-size — those are BUG-005.
- Hover handling in any other component.
- Structural or behavioural changes to the context menu.
