# Task

Replace the raw `rgba(0,0,0,0.08)` background on the table column resize handle with a new design token `--color-resize-handle`, defined in both theme blocks of `themes.css`.

## Specs to load

- `specs/51-styling-architecture.md` — §"No raw values — tokens only" (raw `rgba()` explicitly banned in component files)
- `specs/50-theming.md` — token definition location and format; note that `rgba()` is permitted inside `themes.css` token definitions

## Acceptance criteria

1. `TableView.tsx` contains no raw `rgba()` value anywhere in the file.
2. `--color-resize-handle` is defined in both the light block (`:root, [data-theme="light"]`) and the dark block (`[data-theme="dark"]`) of `src/frontend/styles/themes.css`.
3. The resize handle element uses `var(--color-resize-handle)` for its background.
4. `npx tsc --noEmit` exits 0.

## Done when

No raw `rgba()` literal remains in `TableView.tsx`; the resize handle colour comes from a named token that adapts to both themes.

## Gate command

```
npx tsc --noEmit
```

## Out of scope

- Other inline styles in `TableView.tsx` — `th` padding, tfoot sizing, focus state — those are BUG-001 and BUG-005.
- Resize-handle styling in any other component.
- Changing the resize handle width, cursor, or interaction behaviour.
