# 2025-01-01 Lexical

Lexical is a fast, accessible, and extensible text editor framework developed by Facebook. It provides a modern, lightweight foundation for building complex rich text editors that are highly customizable and performant.

## Key Features

- **Performance**: Lexical is designed to handle large documents with minimal performance overhead.
- **Extensibility**: Provides a plugin-based architecture for adding rich text features.
- **Accessibility**: Built with ARIA standards in mind, ensuring accessible experiences.
- **Type Safety**: Written in TypeScript, offering a strong type system for editor configurations.

---

## Editor State

- **EditorState**: Represents the current state of the editor, including the document structure and formatting.
- **Updates**: Changes to the state are made via updates triggered by user actions or programmatic commands.

```JavaScript
import { EditorState } from 'lexical';

// Example: Creating a new editor state
const editorState = new EditorState();
editor.update(() => {
  editorState.read(() => {
    console.log('Editor state updated!');
  });
});
```

---

## Nodes

- **Nodes**: Building blocks of Lexical's document model, representing elements like paragraphs, headings, lists, or custom elements.
- **Custom Nodes**: Developers can create custom nodes to extend Lexical's functionality.

```JavaScript
import { Node } from 'lexical';

class CustomNode extends Node {
  static getType() {
    return 'custom-node';
  }
  // Implement rendering and other logic here
}
```

---

## Commands

- **Commands**: Used to trigger specific actions within the editor, such as inserting text, formatting, or applying transformations.
- **Predefined Commands**: Includes commands like `INSERT_TEXT_COMMAND` and `FORMAT_TEXT_COMMAND`.

```JavaScript
import { INSERT_TEXT_COMMAND } from 'lexical';

editor.dispatchCommand(INSERT_TEXT_COMMAND, 'Hello, World!');
```

---

## Plugins

- **Plugins**: Modular pieces of logic to enhance the editor’s functionality, such as handling mentions, hashtags, or spell checking.
- **Custom Plugins**: You can create your own plugins to add unique features.

```JavaScript
function CustomPlugin() {
  useLexicalComposerContext();
  // Plugin logic here
  return null;
}
```

---

## Editor API

- **Core Methods**:
  - `update()`: Modify the editor state.
  - `getEditorState()`: Retrieve the current editor state.
  - `registerCommand()`: Listen for specific commands and execute logic.

## Accessibility

- Built to support ARIA attributes and screen readers, making Lexical a good choice for applications requiring high accessibility standards.
