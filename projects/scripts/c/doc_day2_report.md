# **DAY 2 Report**

* **Type precision:** Always match format specifiers and integer widths (`uint16_t` ↔ `%hu`, `int16_t` ↔ `%hd`).
* **Operator precedence awareness:** Use parentheses generously in bit and shift operations.
* **Functional abstraction:** Start writing helper functions (e.g., `swap()`, `parse_line()`) for modularity.
* **Testing mindset:** Add small, systematic test loops to validate intermediate steps.
* **Bitwise mastery:** Keep practicing with masking and shifting — these are core in safety-critical embedded stacks.
