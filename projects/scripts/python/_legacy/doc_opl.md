# OPL

## Coding

1. Strings — manipulation, formatting, methods (`split`, `join`, `strip`, etc.), searching, replacing
2. Collections & Iteration — lists, tuples, dicts, sets; iteration tools (`enumerate`, `zip`, `range`)
3. Comprehensions & Generators — list/dict/set comprehensions, generator expressions, `yield`
4. Data Structures (Advanced) — stacks (via list), queues (via `deque`), sets, tuples, and their methods
5. Algorithms & Complexity — searching, sorting, two-pointer, recursion, and Big-O intuition
6. OOP Essentials — classes, dataclasses, attributes, methods, inheritance vs composition
