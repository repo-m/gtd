# Selection Logic: Memory vs. Reference

Apply this checklist to determine if a topic belongs in the `memory/` system.

### Decision Checklist

- **Utility:** Will I need this while away from my computer or in a high-stakes meeting?
- **Foundational:** Is this a "building block" required to understand advanced topics?
- **Frequency:** Do I need this more than once a month?
- **Searchability:** Is it faster to recall this than to find the documentation?
- **Complexity:** Is the logic (state machine/handshake) too complex to derive on the spot?
- **Interviews:** Is this a common technical interview "litmus test" question?
- **Application:** Am I currently working on a project requiring this knowledge?

---

### Selection Rule

- **Move to Memory:** If you answer **YES** to 3 or more.
- **Keep as Reference:** If it is a static list (error codes, pinouts) or a one-time setup guide.
