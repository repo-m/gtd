# Note Content Checklist: Principles & Maps

Apply this checklist to the content within your Markdown files to ensure they are optimized for long-term retention before moving them into the `memory/` system.

## Principles Checklist

- **The 80/20 Rule:** Does this note focus on the 20% of the protocol/tech that covers 80% of its use cases?
- **Connection:** Does the note explicitly link this topic to a concept I already know (e.g., "SOME/IP is like HTTP for cars")?
- **Chunking - Visuals:** Is there a drawing, Mermaid diagram, or header map included?
- **Chunking - Metaphor:** Have I defined a simple metaphor for the complex logic?
- **Chunking - Summary:** Is there a 1-sentence summary at the top for quick recall?
- Search for topic in all notes and set hashtags

- Networking: "CORE" -> Connection, Output, Role, Encapsulation
