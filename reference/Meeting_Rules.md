# Meetings

- Avoid large meetings
- Avoid frequent meetings
- Leave meeting as soon as it is obvious you are not adding value
- Should it be a meeting?
- One-On-One or All-Staff-Meeting?
- Try to keep meetings as small as possible
- Cancel meeting in time: >=24h
- Set up meeting in time: >=24h
- Elements of a meeting
  - Summary (Optional): What is causing this meeting?
  - Agenda: Topics - Responsible (time box)
  - Goal
- Start and end meeting in time
- Distribute protocol (incl. Attachments) after meeting
