## Note on Sandboxing
It is highly recommended to run Gemini CLI within a sandbox to protect your local environment.
* If using the default Gemini CLI sandboxing, ensure your container has the necessary permissions to read/write to this directory and execute your code artifacts.
* The  skill is purely procedural (reading markdown files) and requires no special network or system permissions beyond file access to this workspace.
