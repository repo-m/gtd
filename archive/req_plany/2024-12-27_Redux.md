# 2024-12-27 Redux

Redux is a standalone state management library often used with React apps to provide centralized state management.
Redux is good for larger apps, apps with complex state management needs, building apps in a team where predictable state management is critical, or all of the above.

## Action & Action Creators

- **Action**: An Action is a JavaScript object with a mandatory type field and an optional payload, which defines an action or event in an app.
- **Additional Fields**: An Action can have additional optional custom fields.

```JavaScript
const addTodoAction = {
  type: 'todo/todoAdded',
  payload: 'Buy milk'
};
```

- **Action Creator**: An Action Creator is a function that helps generate actions more easily, saving code lines and improving reusability.

```JavaScript
const addTodo = text => {
  return {
    type: 'todo/todoAdded',
    payload: text
  };
};
```

## Reducer

- A reducer is a function that receives the current state and an action object, decides how to update the state (if necessary), and returns the new state: `(state, action) => newState`.
- The reducer contains the logic to determine how the application's state should change in response to actions.
  - In an app with a state machine, the reducer implements the state machine logic, including states and transition conditions.
- Multiple reducers can be combined into a single root reducer using `combineReducers`.

```JavaScript
const initialState = { value: 0 };

const todoListUpdated = (state = initialState, action) => {
  if (action.type === 'todo/todoAdded') {
    return {
      // Make a copy of `state` (Redux Rule: Never mutate the state directly)
      ...state,
      value: state.value + 1
    };
  }
  // Return the existing state unchanged if the action is not handled
  return state;
};
```

## Store

- The store is a JavaScript object with methods like getState (to access the state), dispatch (to send actions), and subscribe (to listen for state changes).
- It is created by passing a reducer (or multiple reducers).
- There is always one central store per app: Single Source of Truth
- It holds the central state of the app and manages state transitions based on dispatched actions.

```JavaScript
import { configureStore } from '@reduxjs/toolkit';

const store = configureStore({
  reducer: {
    todoListUpdated, // Combine reducers as an object
    todoListLoaded,
  },
});

console.log(store.getState());
```

## Dispatch

- Dispatch is a method provided by the store object.
- The only way to update the state in the store is by calling `store.dispatch()`.
- It triggers a reducer, which processes the action and updates the state in the store accordingly.
- Middleware (like Redux Thunk) can extend dispatch to handle asynchronous actions.

```JavaScript
store.dispatch({type: 'todo/todoAdded'})
```

- Usually, dispatch is called with an Action Creator, which returns the action object.

```JavaScript
store.dispatch(addTodo('Buy milk'));
```

## Selectors

- Selectors are functions used to extract specific pieces of information from the Redux store's state.
- They help encapsulate the logic for accessing and formatting data, making it reusable and consistent.
- With libraries like `reselect`, memoizing computations is possible, which improves performance by ensuring selectors only recompute when their input state changes.

```JavaScript
const openTodos = selectTodos(store.getState());
```
