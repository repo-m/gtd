# How To Take Smart Notes - #Ahrens

- External structure to think, which compensates limitations of brain
  - Brain reinvents and rewrite memory every time when retrieving information
  - Brain is a machine for jumping to conclusions
  - If we have an old but forgotten idea again -> brains get excited like first time
- Job split between brain and Zettelkasten -> co-evolving
  - Brain: Focus on gist, deeper understanding, big picture --> brain is good associations, spotting patterns and similarities
  - Zettelkasten: Details and References -> Long-term memory that keeps information objectively unaltered
- What to do next? Do not brainstorm - instead Slip-box-storming: look into Zettelkasten (Contexts/Threads, Clusters, Questions, ...)
  - Don't focus on everything decide what to focus on (based on Zettelkasten)
- Learning cycle: Understand, rephrase, then write and link Zettel.
- Creating Zettel: Not collect but develop ideas, arguments, discussions --> Is new note relevant or irrelevant for existing threads?! --> learning by doing
  - Do not worry about completeness: No notes to fill gaps -> only if it helps thinking
- Adding Zettel to Zettelkasten: Question is not under which topic to store the Zettel - INSTEAD - in which context Zettel shall be discovered again
- Topic notes
  - New topic notes -> development of understanding
  - Archivist vs Writer -> Topic/index
  - Archivist: Which key word is most fitting?
  - Writer: In which circumstances will I want to stumble upon this note
- Zettelkasten grows with evolution (not by planning)
  - High motivating since you know what is needed next -> less willpower needed
  - Being stuck with a Project that doesn't seem to be worth doing (e.g. at work) -> demotivating!
  - No top down organization (e.g. by topic) -> buttom up approach
  - Do not create overviews of notes!
- Working on different topics is the strengths of Zettelkasten
