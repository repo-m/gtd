# Integration

- E/E Architecture Transition: Domain to Zonal - Static Physical to Dynamic Logical
    - Trade-Off: Trading **Harness Mass** (pin2pin) for increased **Network Orchestration** and **Timing Jitter** (service2service, #SOME/IP).
    - Latency & Jitter: SerDes - Serialization/Deserialization + switch hops = non-deterministic timing
    - Power Distribution: SW controls power sequencing via eFuses -> Power Delivery Network (PDN) + Power Sequencing 
    - Data Integrity: High-speed links -> cross-functional software/EE problem
- Architecture Components
    - **Central Compute (City Hall/Brain):** Runs POSIX OS (SafeRTOS) and Adaptive AUTOSAR for heavy logic.
    - **Zonal Gateways (Post Office/Nerves):** Utilize MCUs like Infineon Aurix for real-time I/O, power distribution, and CAN-to-Ethernet translation.
    - **Zonal Backbone:** Employs 1Gbps+ Automotive Ethernet with **TSN (Time-Sensitive Networking)** to prioritize safety-critical packets.
- Failure Modes & Resolutions
    - **Power-Up Race Condition:** Resolved by a Global Power State Machine with staggered wake-up routines to prevent gateway message flooding.
    - **Sensitive eFuse** 
    - **Interface Drift:** Mitigated by a Single Source of Truth (SSoT) and automated CI/CD checks to prevent CAN/Ethernet database mismatches.
    - **Thermal-Induced Jitter:** Addressed via Thermal-Performance Mapping and task shedding when CPU throttling adds latency.
    - **Power Brownouts:** Mitigate EMI-induced eFuse sensitivity and brownouts by combining bulk capacitance (EE), compressor shielding (HV), and staggered power-up sequences (SW) to prevent simultaneous high-load surges.
    - **CPU Overload:** Countered by ISR offloading, DMA usage, and Core Affinity adjustments validated via Trace32/Lauterbach profiling.
    - **Priority Inversion:** Prevented by implementing Priority Inheritance Protocols (PIP) within the RTOS.
- Verification & Metrics
    - **Signal Integrity:** Use of **Eye Diagrams** and Mode Conversion Loss analysis to detect EMI from high-voltage switching.
    - **Thermal Physics:** Calculation of Junction-to-Ambient resistance:
    - **Reliability:** Implementation of Dual-Bank (A/B) OTA flashing with automated bootloader rollback to a "Golden" bank.
    - **Diagnostics:** Fault isolation using UDS Service $19 (Read DTC) and $22 (Read DID).
- Critical Toolchain
    - **Vector GL Logger:** Synchronizes CAN, Ethernet, and analog signals for cross-functional root cause analysis.
    - **HiL Simulator:** Provides a virtual environment for testing safety-critical "Duty & Defense" behaviors.
    - **Automotive Oscilloscope:** Bridges electrical signal integrity and software by visualizing physical bit distortion.
    - **Thermal Imaging:** Maps mechanical heat flow to software thermal trip points.
    - **Network Analysis (CANoe/Wireshark):** Validates TSN scheduling, VLAN IDs, and SOME/IP service configurations.
- Categorized Tools (GEM/PURS/NEeD)
    - **Mechanical (GEM):** Torque wrenches and vibration shakers (Geometry); Thermal cameras and leak testers (Environment); Dye penetrants and acoustic microscopy (Material).
    - **Electrical (PURS):** TDR and X-ray (Plugs); Differential probes and Spectrum Analyzers (Utilities); Climate chambers and DMMs (Reliability); Eye diagrams and near-field probes (Signal Integrity).
    - **Software (NEeD):** Protocol analyzers and network taps (Network); Log parsers and DBC/ARXML validators (Encyclopedia); Wireshark and fuzzing tools (Duty & Defense).
    - **Cross-Functional:** GTEM cells for EMI/EMC; Fault Injection rigs for Safety; High-speed loggers for intermittent HW/SW correlation.
